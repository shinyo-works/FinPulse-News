## 再検証で確認した前提

- ピン留めテスト（tests/test_rate_history_layout.py）は rate-history.html のみ対象。ベースルール（`.site-header p` 0.8rem・`#searchInput` height 30px・`tbody td` padding）を固定するが、**メディアクエリ追加は非衝突**。ヘッダー文言は `header.index("金利履歴ビューアー")` の**存在検査**（完全一致ではない）で、この文言を変えるとテスト失敗。
- iframe 分離・2ファイル複製は確定済みの意図的設計（HANDOFF 記録）。ポップオーバー等の共通パターンは**両ファイル同時・同型修正が保守契約**。
- URL に状態を載せない現状は「意図的にやらない」記録がない未着手の機能欠落（初期実装から一貫して不在なだけ）。
- 利用者は所有者本人のみのため、スクリーンリーダー系（#3・#11・#12）は費用対効果で見送り。公開範囲を広げる時に一括対応する。

## B評価（方針を決めてから・2グループ3件）

### #1＋#10 URL ハッシュ同期＋タブタイトル連動（同一コミット）
- switchView / loadReport / selectInstitution で `#rate` / `#date/YYYY-MM-DD` / `#inst/名前` を書き込み、initialize() 冒頭で解釈。不正値は現行の既定動作へフォールバック。
- 実装上の必須事項: (a) hash 復元は必ず loadReport() / switchView() を**経由**させ、reportRequestId 競合対策・rateLoaded 遅延ロード・buildInstitutionFilters 積集合を迂回しない。(b) 機関名は日本語のため `encodeURIComponent` / `decodeURIComponent` の往復必須。(c) by-institution.json のみ失敗の縮退モード（Promise.allSettled）で `#inst/...` を受けた場合は日付モードの既定動作へフォールバック。(d) switchView で document.title を連動更新（文言は #9 の決定に従う）。
- ユーザー確認: (1) 履歴の扱い — (a) replaceState（リロード復元のみ・シンプル・推奨） / (b) pushState（戻るボタンで前の選択に戻れるが、スマホの「戻る」期待と衝突しやすい）。(2) title の粒度 — (a) タブ（新着/金利）のみ（推奨） / (b) 選択中の日付・機関名まで反映。
- 確認: リロード復元・不正hash・戻るボタン・モバイル初期ペインを目視。
- モデル: opus（状態遷移の中枢・自動テストなし）

### #9 ブランド表記・title・カナの統一
- 3ファイルの title / meta / ブランド文言を「FinPulse News」で統一。**変更範囲は brand 文言・title・meta のみで、#subtitle 本文（#2 で2span化する説明文）は対象外**。
- カナの選択で工数が変わる: (a) **「ビューアー」統一** — rate-history のヘッダー文言・テストは無変更で済む（最小工数）。ただし内部文書（Markdown 39箇所の「ヴューアー」）との表記差は残る（内部文書なので放置可）。 (b) **「ヴューアー」統一** — 画面2箇所＋テスト期待文字列の更新が必要。文書はほぼ無傷。
- 確認: unittest 全件＋3ページのタブタイトル目視。
- モデル: sonnet（決定後は機械的な置換）

## C評価（実機確認が先・3件）

- **#4 iOS 自動ズーム**: 所有者が iPhone で金利表を操作するかに依存。対応する場合も `(pointer: coarse)` 系メディアクエリで **font-size のみ**16px化すれば height 30px のベースルールは不変でテスト緩和不要。
- **#8 絵文字・記号の豆腐**: 所有者の実機で公開URLを開き、🏦📅⌕ の3種が表示されるか確認（1分）。豆腐なら該当文字のみ SVG/テキスト化。
- **#16 ポップオーバー位置**: responsive モード各幅でボタンとの乖離が出るか確認。出た場合のみ getBoundingClientRect 基準へ。
- 3件とも「PC のみで使う」なら実質 D に落とせる。

## D評価（やらない・10件）

- **#3 / #11 / #12**（ARIA・aria-live・見出し順）: スクリーンリーダー利用のない所有者専用サイトでは効果が観測されない。公開範囲を広げる時に一括対応。
- **#13** 再試行ボタン: 日付再クリック・リロードという代替導線が既にある。
- **#14** チップ再押下解除: コミット b17d54b とコード内コメントに記録された意図的仕様。「すべて」チップが常設の戻り道。
- **#15** 文字サイズ: ユーザー要望による高密度化の履歴（複数コミット）に逆行。
- **#18** /docs/ の見える URL: 「Pages = main /(root)」の確定契約。構成変更は DATA_ROOT 等へ波及大。
- **#19** 直接アクセスの行き止まり: 直接アクセスは所有者のデバッグ用途のみ。
- **#21** 英語 eyebrow ラベル: 装飾のデザイン言語。情報は h1 が担う。
- **#22** モバイル初期ペイン: 読込失敗時に日付一覧が見えている現挙動が縮退動線として合理的。
